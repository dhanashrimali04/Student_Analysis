## 📌 About The Project

The **Student Data Analysis Project** is a Python-based data analysis project developed using Jupyter Notebook.

The main purpose of this project is to explore student-related data, perform data manipulation, analyze datasets, and create meaningful visualizations to understand patterns and insights hidden within the data.

This project demonstrates practical applications of Python libraries used in Data Analytics and Exploratory Data Analysis (EDA).

## 🎯 Project Objectives

- Understand and explore student datasets.
- Perform data manipulation and preprocessing.
- Apply statistical and numerical operations.
- Analyze data to identify meaningful patterns.
- Create informative and attractive visualizations.
- Develop practical data analysis skills using Python.

## ⚙️ Installation & Setup

Follow these steps to run this project on your local machine.

**1. Clone the repository**

```bash
git clone https://github.com/dhanashrimali04/Student_Analysis.git
```

**2. Navigate to the project directory**

```bash
cd Student_Analysis
```

**3. Install the required libraries**

```bash
pip install numpy pandas matplotlib seaborn jupyter
```

**4. Launch Jupyter Notebook**

```bash
jupyter notebook
```

**5. Open the notebook**

Open `Student_Analysis_Project.ipynb` and execute the cells to explore the analysis.

## 📊 Project Workflow

1. Import the required Python libraries.
2. Load the student dataset using Pandas.
3. Explore and inspect the dataset.
4. Perform data analysis and numerical operations.
5. Create visualizations using Matplotlib and Seaborn.
6. Interpret the results and identify useful insights.
